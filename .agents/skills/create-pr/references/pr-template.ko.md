# 한국어 PR 템플릿

제목과 본문을 한국어로 작성한다. 구체적인 문제와 변경 후 동작을 먼저 설명한다. 작은 PR은 짧은 요약과 검증 결과면 충분하다. 괄호 안 안내문을 최종 diff에 근거한 내용으로 바꾸고, 필요 없는 선택 섹션은 제거한다. 테스트 결과나 이슈 번호를 만들어내지 않는다.

```markdown
## 변경 요약

(어떤 문제를 해결하고 어떤 동작이 가능해지는지 설명한다. 도움이 되면 변경 전후 예시를 포함한다.)

## 검증

(실제로 수행한 검사와 결과를 적는다. 수행하지 않은 검사는 이유를 명시한다.)

## 위험 및 제한사항

(선택: 호환성 문제, 알려진 제한사항, 후속 작업 중 리뷰에 필요한 내용을 적는다.)

## 관련 이슈

(선택: 확인한 관련 이슈를 연결한다. 실제로 해결하는 이슈에만 자동 종료 키워드를 사용한다.)
```

시각적 변경은 리뷰에 도움이 되는 확보된 스크린샷을 첨부한다. 캡처하지 않은 스크린샷이 있다고 쓰지 않는다. 제출 저장소의 필수 템플릿과 체크리스트가 있으면 이를 우선한다.
