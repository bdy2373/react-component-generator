# React 컴포넌트 생성기

프롬프트를 입력하면 AI가 React 컴포넌트를 즉시 생성하고, 실시간 미리보기와 코드를 제공합니다.

## 기술 스택

- **Frontend**: React 19 + TypeScript + Vite
- **Backend**: Bun (AI API 프록시 서버)
- **AI Provider**: Anthropic Claude / Google Gemini (선택 가능)
- **미리보기**: react-live (런타임 렌더링)

## 실행 방법

```bash
# 의존성 설치
bun install

# (선택) .env에 API 키 설정
cp .env.example .env
# .env 파일에 ANTHROPIC_API_KEY 또는 GOOGLE_API_KEY 입력

# API 서버 + 프론트엔드 동시 실행
bun run dev
```

브라우저에서 `http://localhost:5173` 접속 후 사용할 수 있습니다.

- `.env`에 API 키를 설정하면 UI에서 별도 입력 없이 바로 사용 가능
- `.env` 없이도 UI에서 직접 API 키를 입력하여 사용 가능

## 주요 기능

Codex 커밋 보호는 `.codex/hooks.json`에 정의되어 있습니다. 앱의 **Review hooks** 또는 **Settings > Hooks**에서 검토·신뢰한 뒤 사용하세요. 커밋 관련 호출 전에 전체 테스트가 성공해야 하며, 테스트 명령 실패 시 도구 결과를 중단 피드백으로 대체하며, 에이전트는 AGENTS.md 규칙에 따라 작업을 중단하고 실패를 보고합니다. 훅 자체가 턴 종료를 강제하지는 않습니다. Git 훅은 설치하지 않습니다. 검사 대상은 현재 작업 트리이며, 도구 입력의 커밋 문자열 감지 방식이므로 임의의 스크립트·별칭을 통한 모든 커밋까지 강제 차단하는 보안 경계는 아닙니다.

- **멀티 프로바이더**: Anthropic Claude / Google Gemini 선택
- **실시간 미리보기**: 생성된 컴포넌트를 즉시 렌더링
- **새로고침**: 애니메이션 컴포넌트를 리마운트하여 다시 보기
- **재생성**: 같은 프롬프트로 AI에 다시 요청
- **예시 프롬프트**: 시각적 임팩트가 큰 예시 제공
- **작업 자동 저장**: 직접 입력한 API 키, 선택한 Provider, 프롬프트 히스토리, 생성된 컴포넌트를 같은 브라우저의 localStorage에 저장하고 새로고침 시 복원

최근 프롬프트를 선택하면 입력창에서 다시 사용할 수 있습니다. 생성 요청이 실패해도 히스토리는 남으며, 컴포넌트 개별 삭제와 전체 삭제는 저장 목록에도 반영됩니다. Provider를 변경하면 직접 입력한 API 키는 지워집니다.

직접 입력한 API 키는 localStorage에 평문으로 저장되어 같은 출처의 JavaScript(생성된 미리보기 코드 포함)에서 접근할 수 있습니다. 서버의 `.env` 키는 브라우저에 저장하지 않습니다. 브라우저 사이트 데이터를 삭제하면 저장된 작업도 삭제되며, 저장 공간이 부족하거나 저장이 차단된 경우 현재 세션에서만 사용할 수 있습니다.
